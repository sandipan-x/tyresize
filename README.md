# TyreSize

Decode tyre markings like 205/55R16, compare two tyre sizes side by side, and calculate speedometer error percentage before you buy new tyres. Free.

## Features
- Parses 205/55R16 markings into diameter, width, and sidewall height
- Side-by-side comparison of two tyre sizes with verdict
- Speedometer and odometer error percentage calculator
